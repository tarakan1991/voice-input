## Автоматические проверки (выполняются перед каждым коммитом)

- `cargo build --release` — без ошибок
- `cargo test` — все тесты зелёные
- `cargo clippy --all-targets -- -D warnings` — чисто
- `cargo fmt -- --check` — чисто
- `npm run check` (svelte-check + tsc) — 0 ошибок
- `npm run build` — фронтенд собирается
- `cargo tauri build` — .app и .dmg создаются в `src-tauri/target/release/bundle/`

## Чеклист ручной проверки (перед тегом релиза)

Прогоняется целиком на живой машине. Пункты с 🎤 требуют выданных прав
(Микрофон, Универсальный доступ) и скачанных моделей.

### Микрофонный инвариант — критерий приёмки №1

- [ ] 🎤 20 циклов диктовки подряд (стоп по хоткею / по тишине / отмена по Esc /
      отмена кнопкой ✕) — после КАЖДОГО оранжевая точка микрофона в строке
      меню гаснет сразу после остановки записи (до начала распознавания).
- [ ] 🎤 Вне записи нет открытых input-стримов: Настройки macOS → Звук → Вход
      не показывает активности; точка в строке меню не горит.
- [ ] 🎤 Ошибка в середине записи (выдернуть USB-микрофон) — устройство
      освобождено, приложение живо, показано уведомление.
- [ ] С Bluetooth-наушниками и дефолтом «всегда встроенный микрофон»:
      наушники ни разу не переключаются в HFP (качество музыки не проседает
      ни при старте записи, ни во время).

### Фокус и оверлей

- [ ] 🎤 Диктовка в Telegram, в форме браузера и в VS Code: плашка появляется,
      фокус из поля ввода не уходит, текст вставляется в исходное поле.
- [ ] Плашка не перехватывает клики (клик «сквозь» неё попадает в окно под ней),
      кнопка ✕ кликабельна и отменяет диктовку, не забирая фокус.
- [ ] Плашка видна поверх полноэкранного приложения и на втором мониторе
      (появляется на мониторе с курсором).

### Запись и VAD

- [ ] 🎤 Молчание после старта → через тайм-аут диктовка отменяется, ничего
      не вставлено, уведомление показано.
- [ ] 🎤 Речь → молчание: на плашке появляется отсчёт, запись останавливается
      по порогу; продолжение речи во время отсчёта сбрасывает таймер.
- [ ] 🎤 Шум кондиционера/вентилятора не удерживает запись бесконечно
      (VAD не принимает шум за речь) — запись останавливается по тайм-ауту.
- [ ] 🎤 Отбивка «говорите» звучит только после реального старта потока.

### Распознавание и вычитка

- [ ] 🎤 Фраза с англицизмами («задеплой на стейджинг», «создай пул-реквест»)
      распознаётся; словарные замены применяются (например «пи ар» → «PR»).
- [ ] 🎤 Вычитка убирает филлеры и оговорки, расставляет запятые, НЕ меняет смысл.
- [ ] 🎤 Сломать вычитку (выключить сеть при облачном режиме / удалить локальную
      модель) → вставляется сырой текст + уведомление. Диктовка не теряется.
- [ ] 🎤 Латентность: фраза 10–15 с → вставка ≤ 4 c
      (large-v3-turbo + Qwen2.5-3B, Apple Silicon).

### Буфер обмена

- [ ] 🎤 Перед диктовкой скопировать текст — после вставки в буфере снова он.
- [ ] 🎤 Перед диктовкой скопировать картинку (скриншот) — после вставки
      в буфере снова она.
- [ ] 🎤 Смена приложения во время обработки → текст НЕ вставлен вслепую,
      лежит в буфере обмена, уведомление показано, запись есть в истории.

### Мастер, настройки, трей

- [ ] Чистая машина (или `rm -rf ~/Library/Application\ Support/VoiceInput
      ~/.config/voiceinput 2>/dev/null` + сброс прав `tccutil reset Microphone
      com.vixarev.voiceinput && tccutil reset Accessibility
      com.vixarev.voiceinput`): мастер проводит от установки до успешной
      диктовки без единого действия вне приложения.
- [ ] Шаг прав: статусы обновляются сами после выдачи в Системных настройках.
- [ ] Скачивание модели: прогресс, пауза, докачка после обрыва сети,
      сообщение при битом файле (SHA256).
- [ ] Тестовый прогон модели показывает распознанную фразу и время на машине.
- [ ] Хоткей: занятая комбинация честно отклоняется, новая — работает сразу.
- [ ] Трей: иконка меняется (простой/запись/обработка/ошибка/пауза), меню
      работает, «Пауза» снимает хоткей, «Выйти» завершает приложение.
- [ ] Закрытие окна настроек прячет его в трей, приложение продолжает работать.
- [ ] Автозапуск: включить → перелогиниться → приложение поднялось в трее.
- [ ] История: записи появляются, «сырой текст» раскрывается, копирование
      и очистка работают, выключатель истории останавливает запись новых.

### Установка

- [ ] .dmg монтируется, приложение копируется и запускается
      (right-click → Open при quarantine).
- [ ] Повторный запуск после закрытия: конфиг, модели и история на месте.

## Известные ограничения v1 (осознанные, SPEC.md §11, §15)

- Менеджеры буфера обмена видят транзитный вставляемый текст.
- Поля защищённого ввода (пароли): вставка блокируется, текст остаётся
  в буфере, показывается уведомление.
- Детект «хоткей занят» видит только конфликты глобальных хоткеев, не
  внутренних шорткатов приложений.
- Dev-сборки без стабильной подписи теряют TCC-права при пересборке
  (процедура с самоподписанным сертификатом — CLAUDE.md).
